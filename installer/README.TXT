OpenTape 0.1 - tape backup for DOS
==================================

OpenTape is a backup, restore, verify and catalogue program for SCSI tape
drives. It is designed for OpenASPI ASPITAP.SYS and for the documented
interface of the historical ASPITAPE.SYS driver.

OPENTAPE.EXE is the DOS QUILIB frontend. OTAPEWIN.EXE is the shared wxWindows
Win16 frontend for Windows 3.1 and Windows 95/98/ME.

Run INSTALL.EXE to install or update OpenTape. Run INSTALL /U from the
installation directory to remove it. The installer is the GeosOne DOS
Installer: https://github.com/geosone/gdi

This is an early bootstrap build and does not read or write tapes yet.
